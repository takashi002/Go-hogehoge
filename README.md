# Nami（波）

Go で書いた小さな Web アプリです。気分の潮汐と短いひとことを残す、ブラウザ完結の手帖。

## できること

- ランディングページ（ブランド「Nami」）
- 手帖ページでエントリ作成・一覧・削除
- 気分タグ: **凪** / **寄せ** / **嵐**
- データはプロセス内メモリ（再起動でシード状態に戻ります）
- HTMX による部分更新（ページ全体のリロードなし）

## 起動

```bash
go run .
```

ブラウザで http://localhost:8080 を開いてください。

ポートを変える場合:

```bash
PORT=3000 go run .
```

## 構成

```
main.go                 # エントリポイント
internal/store/         # インメモリのエントリストア
internal/server/        # HTTP ハンドラ・テンプレート・静的ファイル
```

## 技術

- Go 1.22+（`net/http` のメソッド付きルーティング）
- `html/template` + `embed`
- HTMX（フォーム送信の部分更新）
